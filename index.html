🎉 为什么选择 SnipX？ ​

极致轻量，快如闪电 ​

SnipX 采用纯 C++ Win32 API 开发，没有任何第三方依赖，体积小于 1MB，启动速度小于 500ms。相比其他截图工具动辄几十 MB 的体积，SnipX 让你的系统更加轻盈。

功能强大，应有尽有 ​

虽然体积小，但功能一点也不少。10 种标注工具、取色器、贴图、录屏、多格式保存、快捷键支持等功能应有尽有，满足你的所有截图需求。

简单易用，开箱即用 ​

无需安装，下载即用。简洁的界面设计，直观的操作方式，让你快速上手。丰富的快捷键支持，让截图更加高效。

开源免费，持续更新 ​

SnipX 采用 MIT 许可证开源，完全免费使用。我们会持续更新和改进，欢迎提出建议和反馈。

🚀 快速开始 ​

1. 下载 SnipX ​

访问 下载页面 下载最新版本。

2. 运行程序 ​

双击 SnipX.exe 运行程序。

3. 开始截图 ​

按 Alt+X 开始区域截图，或按 Alt+F 进行全屏截图。

4. 标注和保存 ​

使用工具栏的标注工具进行标注，按 Ctrl+S 保存或 Ctrl+C 复制到剪贴板。
