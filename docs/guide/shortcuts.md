# 快捷键

SnipX 提供了丰富的快捷键，让截图更加高效。

## 🎯 全局快捷键

这些快捷键在任何时候都可以使用。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F1` | 启动截图 | 启动区域截图 |
| `Ctrl+Alt+A` | 启动截图 | 启动区域截图（备用） |

---

## 📸 截图模式快捷键

这些快捷键在截图模式下使用。

### 基本操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Esc` | 取消 | 取消截图并退出 |
| `Enter` | 确认 | 确认选区并进入编辑模式 |
| `Ctrl+A` | 全屏 | 选择全屏 |
| `R` | 取色 | 进入取色模式 |
| `H` | HSL | 切换到 HSL 取色模式 |

### 选区调整

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` | 上移 | 选区上移 1px |
| `↓` | 下移 | 选区下移 1px |
| `←` | 左移 | 选区左移 1px |
| `→` | 右移 | 选区右移 1px |
| `Shift+↑` | 上移 | 选区上移 10px |
| `Shift+↓` | 下移 | 选区下移 10px |
| `Shift+←` | 左移 | 选区左移 10px |
| `Shift+→` | 右移 | 选区右移 10px |

---

## 💡 快捷键技巧

### 技巧 1：快速截图

使用 `F1` 快速启动截图，比 `Ctrl+Alt+A` 更方便。

### 技巧 2：精确调整

使用方向键可以精确调整选区位置，配合 `Shift` 可以快速移动。

### 技巧 3：快速复制

双击选区可以快速复制并退出，无需按 `Ctrl+C`。

### 技巧 4：工具切换

使用数字键可以快速切换工具，比点击工具栏更快。

### 技巧 5：撤销重做

`Ctrl+Z` 和 `Ctrl+Y` 可以撤销和重做操作，支持多步操作。

---

## 🔍 快捷键冲突

如果 SnipX 的快捷键与其他程序冲突：

1. **检查冲突程序**：查看是哪个程序占用了快捷键
2. **关闭冲突程序**：临时关闭占用快捷键的程序
3. **更改快捷键**：在设置中更改 SnipX 的快捷键（未来版本）
4. **使用备用快捷键**：使用 `Ctrl+Alt+A` 代替 `F1`
