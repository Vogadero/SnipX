# 快捷键

SnipX 提供了丰富的快捷键，让截图更加高效。

## 🎯 全局快捷键

这些快捷键在任何时候都可以使用。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Alt+X` | 区域截图 | 启动区域截图 |
| `Alt+F` | 全屏截图 | 直接截取虚拟桌面全屏 |
| `Alt+X` + `Shift` | 上次选区截图 | 复用最近一次区域选区；没有记录时进入区域截图 |

---

## 📸 截图模式快捷键

这些快捷键在截图模式下使用。

### 基本操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Esc` | 取消 | 取消截图并退出 |
| `Enter` | 确认 | 确认选区并进入编辑模式 |
| `R` / `H` | 取色 | 退出截图覆盖层并进入取色器 |

### 选区调整

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` | 上移 | 选区上移 1px |
| `↓` | 下移 | 选区下移 1px |
| `←` | 左移 | 选区左移 1px |
| `→` | 右移 | 选区右移 1px |
| `Shift+↑` | 上移 | 选区上移 10px |
| `Shift+↓` | 下移 | 选区下移 10px |
| `Shift+←` | 左移 | 选区左移 10px |
| `Shift+→` | 右移 | 选区右移 10px |

---

## 🎨 编辑模式快捷键

这些快捷键在编辑模式下使用。

### 文件操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+S` | 保存 | 打开保存对话框 |
| `Ctrl+C` | 复制 | 复制到剪贴板 |
| `Esc` | 关闭 | 关闭编辑器 |

### 编辑操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+Z` | 撤销 | 撤销上一步操作 |
| `Ctrl+Y` | 重做 | 重做上一步操作 |
| `Delete` | 删除 | 删除选中的标注 |
| `Backspace` | 删除 | 删除选中的标注（备用） |

### 工具切换

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `1` | 矩形 | 切换到矩形工具 |
| `2` | 椭圆 | 切换到椭圆工具 |
| `3` | 箭头 | 切换到箭头工具 |
| `4` | 直线 | 切换到直线工具 |
| `5` | 铅笔 | 切换到铅笔工具 |
| `6` | 文字 | 切换到文字工具 |
| `7` | 序号 | 切换到序号工具 |
| `8` | 高亮 | 切换到高亮工具 |
| `9` | 马赛克 | 切换到马赛克工具 |
| `0` | 模糊 | 切换到模糊工具 |

## 📌 贴图窗口快捷键

这些快捷键在贴图窗口中使用。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Esc` | 关闭 | 关闭贴图窗口 |
| `Ctrl+C` | 复制 | 复制贴图到剪贴板 |

## 🎯 取色模式快捷键

这些快捷键在取色模式下使用。

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Esc` | 退出 | 退出取色模式 |
| `R` / `H` | 切换显示 | 循环切换 RGB / HSV / HSL 显示模式 |
| `C` | 复制 | 复制当前显示模式的颜色值 |
| `1` / `2` / `3` / `4` | 复制格式 | 分别复制 HEX / RGB / HSL / HSV |
| `鼠标左键` | 复制 HEX | 复制当前颜色的 HEX 值 |

## 💡 快捷键技巧

### 技巧 1：快速截图

使用 `Alt+X` 快速启动区域截图；需要直接截取全屏时使用 `Alt+F`。

### 技巧 2：精确调整

使用方向键可以精确调整选区位置，配合 `Shift` 可以快速移动。

### 技巧 3：快速复制

双击选区可以快速复制并退出，无需按 `Ctrl+C`。

### 技巧 4：工具切换

使用数字键可以快速切换工具，比点击工具栏更快。

### 技巧 5：撤销重做

`Ctrl+Z` 和 `Ctrl+Y` 可以撤销和重做操作，支持多步操作。

---

## 🔍 快捷键冲突

如果 SnipX 的快捷键与其他程序冲突：

1. **检查冲突程序**：查看是哪个程序占用了快捷键
2. **关闭冲突程序**：临时关闭占用快捷键的程序
3. **更改快捷键**：在设置中更改 SnipX 的快捷键（未来版本）
4. **全屏截图**：使用 `Alt+F` 直接全屏截图

### 初学者

先记住这些最常用的快捷键：

- `Alt+X` - 区域截图
- `Alt+F` - 全屏截图

- `Ctrl+S` - 保存
- `Ctrl+C` - 复制

- `Ctrl+Z` / `Ctrl+Y` - 撤销/重做

- `数字键` - 快速切换工具

熟练使用所有快捷键，提高截图效率：

- 所有工具切换快捷键
