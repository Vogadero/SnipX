快捷键 ​

SnipX 提供了丰富的快捷键，让截图更加高效。

🎯 全局快捷键 ​

这些快捷键在任何时候都可以使用。

快捷键功能说明
Alt+X区域截图启动区域截图
Alt+F全屏截图直接截取虚拟桌面全屏
Alt+X + Shift上次选区截图复用最近一次区域选区；没有记录时进入区域截图

📸 截图模式快捷键 ​

这些快捷键在截图模式下使用。

基本操作 ​

快捷键功能说明
Esc取消取消截图并退出
Enter确认确认选区并进入编辑模式
R / H取色退出截图覆盖层并进入取色器

选区调整 ​

快捷键功能说明
↑上移选区上移 1px
↓下移选区下移 1px
←左移选区左移 1px
→右移选区右移 1px
Shift+↑上移选区上移 10px
Shift+↓下移选区下移 10px
Shift+←左移选区左移 10px
Shift+→右移选区右移 10px

🎨 编辑模式快捷键 ​

这些快捷键在编辑模式下使用。

文件操作 ​

快捷键功能说明
Ctrl+S保存打开保存对话框
Ctrl+C复制复制到剪贴板
Esc关闭关闭编辑器

编辑操作 ​

快捷键功能说明
Ctrl+Z撤销撤销上一步操作
Ctrl+Y重做重做上一步操作
Delete删除删除选中的标注
Backspace删除删除选中的标注（备用）

工具切换 ​

快捷键功能说明
1矩形切换到矩形工具
2椭圆切换到椭圆工具
3箭头切换到箭头工具
4直线切换到直线工具
5铅笔切换到铅笔工具
6文字切换到文字工具
7序号切换到序号工具
8高亮切换到高亮工具
9马赛克切换到马赛克工具
0模糊切换到模糊工具

📌 贴图窗口快捷键 ​

这些快捷键在贴图窗口中使用。

快捷键功能说明
Esc关闭关闭贴图窗口
Ctrl+C复制复制贴图到剪贴板
Ctrl+S保存保存贴图到文件
鼠标滚轮缩放缩放贴图

🎯 取色模式快捷键 ​

这些快捷键在取色模式下使用。

快捷键功能说明
Esc退出退出取色模式
R / H切换显示循环切换 RGB / HSV / HSL 显示模式
C复制复制当前显示模式的颜色值
1 / 2 / 3 / 4复制格式分别复制 HEX / RGB / HSL / HSV
鼠标左键复制 HEX复制当前颜色的 HEX 值

⚙️ 自定义快捷键 ​

目前 SnipX 不支持自定义快捷键，但我们计划在未来版本中添加此功能。

如果你有特定的快捷键需求，欢迎在 GitHub Issues 中提出建议。

💡 快捷键技巧 ​

技巧 1：快速截图 ​

使用 Alt+X 快速启动区域截图；需要直接截取全屏时使用 Alt+F。

技巧 2：精确调整 ​

使用方向键可以精确调整选区位置，配合 Shift 可以快速移动。

技巧 3：快速复制 ​

双击选区可以快速复制并退出，无需按 Ctrl+C。

技巧 4：工具切换 ​

使用数字键可以快速切换工具，比点击工具栏更快。

技巧 5：撤销重做 ​

Ctrl+Z 和 Ctrl+Y 可以撤销和重做操作，支持多步操作。

🔍 快捷键冲突 ​

如果 SnipX 的快捷键与其他程序冲突：

  1. 检查冲突程序：查看是哪个程序占用了快捷键
  2. 关闭冲突程序：临时关闭占用快捷键的程序
  3. 更改快捷键：在设置中更改 SnipX 的快捷键（未来版本）
  4. 全屏截图：使用 Alt+F 直接全屏截图

🎓 学习建议 ​

初学者 ​

先记住这些最常用的快捷键：

  • Alt+X - 区域截图
  • Alt+F - 全屏截图
  • Enter - 确认选区
  • Ctrl+S - 保存
  • Ctrl+C - 复制
  • Esc - 取消/关闭

进阶用户 ​

掌握这些提高效率的快捷键：

  • Ctrl+Z / Ctrl+Y - 撤销/重做
  • 方向键 - 精确调整
  • 数字键 - 快速切换工具
  • R - 取色模式

高级用户 ​

熟练使用所有快捷键，提高截图效率：

  • 所有工具切换快捷键
  • 所有选区调整快捷键
  • 所有取色模式快捷键
