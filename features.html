功能特性 ​

SnipX 提供截图、标注、贴图、取色、录屏和便携发布能力，适合需要轻量 Windows 截图工具的日常场景。

📸 截图功能 ​

区域截图 ​

拖拽鼠标选择任意区域进行截图，支持实时显示选区尺寸。

使用方法：

  1. 按 Alt+X 启动区域截图
  2. 拖拽鼠标选择区域
  3. 按 Enter 确认，或松开鼠标完成选区

特性：

  • ✅ 实时显示选区尺寸
  • ✅ 放大镜辅助精确选择
  • ✅ 方向键微调选区（1px / 10px）
  • ✅ 支持窗口边界检测

全屏截图 ​

一键截取整个虚拟桌面，支持多显示器。

使用方法：

  • 按 Alt+F 进行全屏截图

特性：

  • ✅ 支持多显示器虚拟桌面
  • ✅ 自动获取完整屏幕范围
  • ✅ 截图后直接进入编辑器

窗口检测 ​

区域截图模式下移动鼠标到窗口上，SnipX 会自动识别并高亮窗口边界。

使用方法：

  1. 按 Alt+X 启动区域截图
  2. 移动鼠标到目标窗口
  3. 点击鼠标左键选择该窗口区域

滚动截图 ​

从托盘菜单触发，对当前前台窗口执行简化滚动截图。

使用方法：

  1. 激活需要截图的窗口
  2. 右键托盘图标，选择「滚动截图」
  3. SnipX 会采集多段内容并拼接成长图

🎨 标注工具（10 种） ​

1. 矩形工具 ​

绘制矩形边框，可调整颜色和粗细。

2. 椭圆工具 ​

绘制椭圆或圆形标注。

3. 箭头工具 ​

添加箭头指示，支持多种箭头样式（→ ⇒ ➡ ⇢）。

4. 铅笔工具 ​

自由绘制线条，适合圈画重点。

5. 文字工具 ​

在截图上添加文字说明。

6. 直线工具 ​

绘制直线，可调整颜色和粗细。

7. 序号标签 ​

添加自动递增的序号标签，便于说明步骤。

8. 高亮工具 ​

使用半透明高亮强调重点区域。

9. 马赛克工具 ​

像素化遮挡敏感信息。

10. 模糊工具 ​

使用模糊效果柔和遮挡内容。

🔧 编辑功能 ​

选中标注 ​

点击标注对象即可选中，显示调整手柄。

拖拽移动 ​

选中标注后，按住鼠标左键拖拽移动。

调整大小 ​

选中标注后，拖拽调整手柄调整大小。

删除标注 ​

选中标注后，按 Delete 或 Backspace 删除。

撤销/重做 ​

  • Ctrl+Z 撤销
  • Ctrl+Y 重做

工具快捷切换 ​

编辑器支持数字键快速切换工具：1 到 9 和 0。

💾 保存功能 ​

PNG 格式 ​

无损压缩，适合保留截图细节。

JPG 格式 ​

可调质量（1-100），适合照片类截图。

BMP 格式 ​

无压缩位图格式，兼容性好。

自动保存 ​

可在设置中启用自动保存，将截图保存到指定目录并使用时间戳命名。

📋 剪贴板功能 ​

复制到剪贴板 ​

按 Ctrl+C 将当前编辑结果复制到剪贴板。

双击复制 ​

双击截图区域可快速复制并退出。

🎯 取色器功能 ​

启动取色 ​

  • 截图模式下按 R 或 H
  • 或右键托盘图标选择「取色器」

显示与复制 ​

  • R / H：循环切换 RGB / HSV / HSL 显示模式
  • C：复制当前显示模式的颜色值
  • 1：复制 HEX
  • 2：复制 RGB
  • 3：复制 HSL
  • 4：复制 HSV
  • 鼠标左键：复制 HEX

📌 贴图功能 ​

截图贴回桌面 ​

截图后点击工具栏的贴图按钮，可将截图贴回桌面作为参考。

特性：

  • ✅ 始终置顶
  • ✅ 可拖拽移动
  • ✅ 鼠标滚轮缩放
  • ✅ 透明度调节
  • ✅ 鼠标穿透

剪贴板贴图 ​

右键托盘图标选择「剪贴板贴图」，可将剪贴板中的位图创建为贴图窗口。

🎬 录屏功能 ​

SnipX 支持轻量录屏帧序列采集。

使用方法：

  1. 右键托盘图标，选择「开始录屏」
  2. 再次打开托盘菜单，选择「停止录屏」
  3. 帧序列会保存到图片目录下的 SnipXRecordings 文件夹

说明：

  • 当前录屏实现以 PNG 帧序列为主
  • 会生成基础 GIF 文件入口，完整高保真 GIF/视频编码可在后续版本增强
  • 当前不录制音频

⚙️ 设置功能 ​

启动模式 ​

  • 托盘模式：启动后最小化到托盘
  • 截图模式：启动后立即截图

开机自启 ​

可在设置中启用或关闭随 Windows 启动。

托盘图标 ​

可显示或隐藏系统托盘图标。

保存设置 ​

支持默认格式、保存路径、JPG 质量、文件名前缀和自动保存目录配置。

标注设置 ​

支持默认标注颜色和默认粗细配置。

🌍 多语言支持 ​

SnipX 已接入轻量本地化模块，支持中文和英文文本。

📊 性能特性 ​

  • 纯 C++17 + Win32 API + GDI+
  • 无第三方运行时依赖
  • 支持 MSVC、MinGW 和 CMake 构建
  • 便携版可静态链接 MSVC runtime

🔒 安全特性 ​

  • 完全本地运行
  • 不收集用户数据
  • 图片上传当前为本地导出待上传图片，不会自动上传到外部服务
